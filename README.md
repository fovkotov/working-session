# Звуковой шрифт

Гарнитура, у которой вместо начертаний — звук. Каждая буква латиницы это гранула полевой
записи, выбранная так, чтобы отличаться от остальных на слух. Набранный текст звучит:
слова и фразы собираются из «букв», как из глифов.

Громкость внутри буквы идёт по её контуру: верх звуковой волны обводит верх глифа, низ —
низ. Поэтому набранное слово читается в собственной форме сигнала — у `t` видна стойка,
у `o` овал, у `p` вынос вниз.

Шрифт тематический по определению: из какой папки записей собран — так и звучит.
Первая гарнитура `RUMBLE 24—29` набрана из шести записей низкого гула помещения (67 секунд).

## Запустить

```sh
cd web && python3 -m http.server 8791
# открыть http://127.0.0.1:8791
```

Нужен локальный сервер: страница читает `font.json` и сэмплы через `fetch`,
с `file://` это не работает.

## Как набрать новую гарнитуру

Любая папка с аудио (`wav`, `m4a`, `mp3`, `aif`, `flac`, `ogg`) превращается в шрифт:

```sh
python3 tools/extract.py \
  --in ~/recordings/metro \
  --id metro \
  --name "METRO" \
  --about "Перегон, двери, объявления"
```

Скрипт добавит гарнитуру в `web/fonts/index.json`, и она появится в селекторе на странице.
Материала стоит давать хотя бы минуту — иначе 26 кластеров получатся слишком похожими.

Проверить, насколько буквы различимы:

```sh
python3 tools/legibility.py metro
```

Считает расстояния между глифами по спектру, по форме огибающей и вместе, выводит самые
похожие пары. Для `RUMBLE 24—29`: вместе — среднее 0.70, минимум 0.26.

Посмотреть, как буква легла в волну, прямо в терминале:

```sh
python3 tools/waveprint.py metro bdop
python3 tools/letterform.py            # контуры, снятые со шрифта-источника
```

## Как устроен отбор букв

1. **Нарезка.** Записи режутся на гранулы по 300 мс с шагом 50 мс, тихие выбрасываются.
2. **Тембровый портрет.** Для каждой гранулы: 18 мел-полос (без громкости), спектральный
   центр, плоскость спектра, наклон огибающей, частота переходов через ноль.
3. **Отбор 26.** K-means на 26 кластеров, из каждого берётся медоида — самый типичный
   представитель. Так буквы максимально не похожи друг на друга.
4. **Роли и ширины.** Пять самых тональных гранул становятся гласными, остальные —
   согласными, нарезанными от пика громкости. Согласные расставлены по алфавиту в порядке
   роста яркости: `b` самая глухая, `z` самая звонкая. Длительность буквы пропорциональна
   её ширине в наборе, так что шрифт получается пропорциональным: `l` — 110 мс, `m` — 219 мс.
5. **Очертание.** Буква растеризуется (`tools/letterform.py`), для каждой колонки пикселей
   берутся верхний и нижний край краски. Собственная огибающая гранулы снимается делением
   на сглаженную пиковую огибающую, и её место занимает контур буквы: положительная
   полуволна умножается на верхний контур, отрицательная — на нижний. Масштаб общий на весь
   алфавит, поэтому выносные элементы громче овалов (разброс RMS около 7 dB) — это
   вертикальный ритм набора, который слышно.
6. **Высота.** Однородный материал даёт похожие буквы, поэтому у каждой есть своя высота,
   вырезанная прямо из записи с нужной скоростью. Гласные идут от тёмной `u` (−7 st)
   к светлой `i` (+7 st), высоты согласных подбираются оптимизацией по тембру и форме:
   максимизируется различимость самой похожей пары букв.

## Оси начертания

Как у вариативного шрифта, только слышно. Сэмплы не меняются — меняется то, как они набраны:
темп, трекинг (вплоть до наложения букв друг на друга), высота, насыщенность
(light → black: фильтр, подъём низа, насыщение), ширина (стерео), пространство (ревербератор),
рукописность (разброс тайминга, высоты и громкости). Есть пресеты, экспорт фразы в WAV
и экспорт набранной строки в PNG (2400 px, та же отрисовка, что на экране).
Клавиша «/» (та же физическая и в латинице, и в кириллице) копирует волну в SVG: только глифы, один цвет, без фона.

Кириллица на вводе транслитерируется, цифры подменяются похожими буквами, знаки препинания
дают паузы разной длины, заглавная звучит тяжелее. Если кликнуть вне поля ввода, можно играть
буквами с клавиатуры.

## Структура

```
tools/extract.py       нарезка записей в гарнитуру
tools/letterform.py    контуры букв: растеризация глифа в огибающую
tools/legibility.py    проверка различимости букв
tools/waveprint.py     форма волны готовых глифов в ASCII
tools/analyze.py       разведка исходного материала: огибающая, события, спектр
web/index.html         specimen-страница
web/app.js             движок набора: расписание, тракт, отрисовка, экспорт
web/fonts/<id>/        font.json + samples/a.wav … z.wav
raw/                   исходные записи, сконвертированные в wav 48k моно
```
